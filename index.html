Architecture

Built for Demanding Developers

Engineered from the ground up for maximum safety, speed, and cross-ecosystem intelligence.

⚡

Rayon Parallel Work-Stealing Traversal

Unlike sequential scanners that crawl folder-by-folder, nodewipe distributes disk traversal across all available CPU cores with Rayon. Subdirectories are split across worker threads, computing real physical disk footprints in parallel.

🛡️

Zero-Risk Excision & CoW

Moves to OS Trash by default. Supports instant Copy-on-Write (reflink) snapshots on Btrfs/APFS/XFS with 0ms space penalty, plus atomic .tar.gz archiving with path-traversal prevention.

🩺

System Doctor & Stale Audits

Audit your entire machine with nodewipe doctor ~. Discovers your oldest untouched build directories and surfaces high-impact quick wins with Git staleness awareness.

Never. nodewipe enforces strict marker file verification. For example, an ambiguous directory like dist/ or build/ will only be recognized if a valid marker (e.g. package.json, CMakeLists.txt, or Cargo.toml) exists directly beside it. Furthermore, nodewipe checks Git working tree state and moves files to your OS Trash by default instead of unrecoverable unlinks.

On modern filesystems like Btrfs (Linux), APFS (macOS), and XFS (Linux), nodewipe leverages filesystem block reflink snapshotting. This allows creating a complete rollback snapshot in 0 milliseconds using 0 bytes of additional disk space. On other filesystems, nodewipe falls back automatically to compressed .tar.gz archiving with path-traversal safeguards.
