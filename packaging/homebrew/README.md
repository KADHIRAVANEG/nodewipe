# Homebrew Tap for nodewipe

Official Homebrew tap for [nodewipe](https://github.com/KADHIRAVANEG/nodewipe) — Find and reclaim gigabytes of disk space from stray developer artifacts across 13+ ecosystems.

## Installation

```bash
brew tap kadhiravaneg/nodewipe
brew install nodewipe
```

Or in a single command:

```bash
brew install kadhiravaneg/nodewipe/nodewipe
```

## Updating

```bash
brew update
brew upgrade nodewipe
```

## Features Installed
- Full `nodewipe` CLI binary.
- Complete man page (`man nodewipe`).
- Shell tab completions for Bash, Zsh, and Fish.
